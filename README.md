# Retro Game Co.

An e-commerce website for a used retro video game store, built for my SDC260 project by Joshua Farr.

## Purpose

Retro Game Co. sells tested, cleaned, and graded used games for classic consoles (NES, SNES, N64, Genesis, PlayStation, Game Boy). Shoppers can browse the catalog, filter by console, view game details, add games to a cart, and complete a simulated checkout.

## Pages

- Store Homepage
- Shop / Catalog
- Product Detail
- About / Contact
- Cart
- Checkout
- Order Confirmation

## Tech Stack

- HTML, CSS, JavaScript
- Product data stored in a JavaScript array
- Cart saved in the browser with `localStorage`
- Hosted on GitHub Pages
